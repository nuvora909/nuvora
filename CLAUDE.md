# Nuvora: working notes for Claude

Nuvora is a pre-launch online school for data science and AI/ML. The owner works alone and asks Claude to make
every change: website text and sections, programs and prices, batches, materials and fixes. Do the work end to
end: change it, test it, commit it, push it, and report what changed in plain words.

## Where things live

- **Website:** `web/` is built into static pages by `scripts/build-site.mjs`.
  - Pages are in `web/pages/`. Shared layout, header and footer are in `web/lib/layout.mjs`; components in `web/lib/components.mjs`.
  - Data is in `web/data/` (site facts, owner facts, certifications) and `scripts/catalog.mjs` (programs, terms, lessons, tuition: the single source of truth).
- **Student and staff portal:** `portal/`, with no build step. The admin area is in the portal for admin accounts. The owner's guide is `docs/admin-guide.md`.
- **Database:** `supabase/migrations/`, where all access rules are enforced. `supabase/seed.sql` is generated by `npm run seed`; never edit it by hand.
- **Local stand-in for Supabase:** `server/`. Run `npm run dev`, then open http://127.0.0.1:5173/ (site) and /portal/.

## Owner requests, and how to handle them

| The owner asks to… | Do this |
|---|---|
| Change text, a section, images or layout on the website | Edit `web/`, rebuild, check the page at 1280 and 390 in light and dark mode |
| Change a price, duration, term or lesson | Edit `scripts/catalog.mjs`, run `npm run seed`, and check every page that shows it |
| Create a batch, enrol a student, record a payment, pause or restore access, upload a PDF | Point them to the admin area (`docs/admin-guide.md`). For bulk or unusual changes, write a migration or script with tests |
| Add a new program | Add it to `scripts/catalog.mjs` (terms, lessons, projects, tuition), seed, add its cover art and data, and update tests |

## Rules that never bend

- **Honesty (pre-launch):** only state what is true today.
  - Nothing invented: no testimonials, ratings, learner counts, outcomes, salaries, partners, company logos, accreditation or "most popular".
  - The credential is "Nuvora certificate of completion · not an accredited degree".
  - Rule-based features are not called AI.
  - Unknown owner facts (`OWNER` in `web/data/site.mjs`) show as "to be published before the first batch".
  - Stock media is labelled.
- **Videos are never downloadable from any source.** Only PDFs download.
- **Access is decided by the database using its own clock**, never by client time or client role. That includes join links and the 30-day unpaid rule.
- **Accessibility:** WCAG 2.2 AA, 44px touch targets, keyboard use, reduced motion respected, no sideways scroll at 320px.
- **Never handle the owner's real passwords or keys.** Demo accounts in `server/demo-accounts.mjs` are local only; never repeat the demo password.

## Testing: every change, three times

- `node tests/run-3x.mjs` runs the database, server, website and browser suites three times in a row. All three runs must pass.
- `node tests/sabotage.mjs` must catch every deliberate break.
- Fix flaky tests at the cause; never add retries or weaken assertions.
- Browser tests use Microsoft Edge. Set `NUVORA_E2E_PORT` to run two copies side by side.
