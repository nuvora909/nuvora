# Website review: public site (site/index.html)

Date: 2026-10-02. Method: 8 independent reviewers (one per dimension) read the code and cited line numbers; a 9th verified the evidence, removed anything that would require invented proof, and merged the results into ordered work packages. Line numbers refer to site/index.html at commit time.

## Scorecard

| Dimension | Rating | Summary |
|---|---|---|
| Program discovery | weak | The browsing UI is polished and the start and apply-by dates are correct, but there are no prerequisites, weekly hours, live schedule, comparison or credential status, and the format and length facts are wrong. |
| Trust/credibility | poor (biggest weakness) | Named sample testimonials, fictional faculty, rolling 'Live' events, invented statistics, a fake login and an outdated privacy notice outweigh honest disclaimers buried on #legal. There is no legal entity, contact, About page or refund policy. |
| Conversion | weak | Too many competing CTAs (counselling ×3 on one screen, AI everywhere), no Apply on the home page, an 'Apply' that leads to a page with no form, and a counselling form that saves nothing and has no phone field. |
| Personalization | weak | Three disconnected tools (matcher, finder, chat) with fake 86%/72% scores, an eligibility bug, no memory and no local-time or cost logistics. On a normal host the AI falls back to keywords. |
| Gamification | mostly absent | The portal has honest raw data (90%-watched slices, rubric, attempts) but only progress bars and a toast. Game-like elements on the site (credit-earned quiz, tested-out chip, fit rings) mislead. |
| Social proof/outcomes | poor (actively misleading) | Every outcome signal on the site is fabricated or implied. Honest pre-launch proof exists (trial lesson, competency maps, real portal), but there is no consented evidence pipeline. |
| Mobile readiness | unverified / likely broken | Lots of responsive CSS, but with no viewport or doctype it is mostly inert when self-hosted. Other problems: 320px clipping hidden by overflow-x:clip, a 19 MB hero video, Three.js on every route, sub-16px inputs, and zero mobile tests. Needs measured Playwright runs and real devices. |
| SEO/content architecture | missing | A fragment with only <title>Nuvora</title>, hash routing into an empty <main>, no meta, canonical, OG, JSON-LD, robots or sitemap. The content must be made truthful before it is ever indexed. |
