B.S. Data Science

Statistics, Python and SQL through to experiment design and production dashboards.

Program Overview

Level

Bachelor’s-level program

Duration

3–4 years part-time

Weekly Commitment

8–12 hours/week

Credential

Nuvora certificate of completion · not an accredited degree

What You'll Learn

Core Competency: Data Science

Specialization Track: data-science

Capstone Project: Take a public dataset from question to a live dashboard, and write a decision memo for a stakeholder.

Terms of Study

  1. Python for data – Python Proficiency
  2. Mathematics for data – Math Foundations
  3. Probability & statistics – Statistical Thinking
  4. Databases & SQL – SQL Fluency
  5. Exploration & visualization – Data Storytelling
  6. Regression & modeling – Regression Modeling
  7. Experimentation – Experiment Design
  8. Machine learning for analysts – ML Foundations
  9. Data engineering basics – Data Pipelines
  10. Communication & ethics – Responsible Communication
  11. Applied domains – Applied Analytics
  12. Capstone: Data Science Capstone

Tools & Technologies

Python, pandas, SQL, scikit-learn, Tableau, dbt, Git

Career Paths

Prepares learners for roles such as:

  • Data Analyst
  • Senior Data Analyst
  • Data Scientist
  • Business Intelligence Analyst

Admission Requirements

Prerequisites

High-school mathematics · No coding experience needed: term 1 teaches Python

Helpful Background

Spreadsheets · Curiosity about numbers and decisions

How You'll Learn

Learning Format

Flexible + live: Watch lessons any time, plus two live Zoom sessions a week (recorded)

Assessment Method

Projects graded by instructors on a four-level mastery rubric

Support Structure

Instructor grading with written feedback, office hours, and peer collaboration
