Certificate in Python & Data Analysis

A focused 12-week start in Python, SQL and data analysis.

Program Overview

Level: Certificate program

Duration: 12 weeks (one term)

Weekly Commitment: 8–10 hours/week

Credential: Nuvora certificate of completion · not an accredited degree

What You'll Learn

Core Competency: Data Science

Specialization Track: data-science

Capstone Project: Publish a cleaned, analysed dataset notebook to your public portfolio.

Weekly Breakdown

  1. Python Fundamentals – Variables, Data Types, Control Flow
  2. Python Intermediate – Functions, Modules, File Handling
  3. Python Advanced – OOP, Libraries, Virtual Environments
  4. SQL Basics – Queries, Filtering, Aggregation
  5. SQL Advanced – Joins, Subqueries, Window Functions
  6. Data Analysis with Python – Pandas, NumPy, Data Cleaning
  7. Data Visualization – Matplotlib, Seaborn, Plotly
  8. Statistics for Data Analysis – Descriptive Stats, Hypothesis Testing
  9. Data Wrangling – Cleaning, Transformation, Preparation
  10. Exploratory Data Analysis – Patterns, Trends, Insights
  11. Applied Data Analysis – Real-world Case Studies
  12. Capstone Project Development – From Concept to Publication
  13. Portfolio Review & Presentation – Final Project Showcase

Tools & Technologies
