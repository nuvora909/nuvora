M.S. Applied Machine Learning

Production machine learning, deep learning architectures and responsible deployment, for working engineers.

Program Overview

Level

Master’s-level program

Duration

12–18 months part-time

Weekly Commitment

10–14 hours/week

Credential

Nuvora certificate of completion · not an accredited degree

What You'll Learn

Core Competency: Machine Learning & MLOps

Specialization Track: engineering-to-ai

Capstone Project: An industry-scale project on public or permitted data, presented and defended to instructors.

Terms of Study

  1. Software Engineering Fundamentals – Code Quality & Testing
  2. Data Engineering – ETL Pipelines & Data Warehousing
  3. Machine Learning Engineering – Feature Stores & Model Training
  4. Deep Learning Production – Model Serving & Monitoring
  5. MLOps & Automation – CI/CD for ML Models
  6. Cloud Architecture – AWS, GCP & Azure Services
  7. Experiment Tracking & Model Registry
  8. Security & Compliance – Data Privacy & Model Governance
  9. Capstone: Applied ML Capstone Project

Tools & Technologies

PyTorch, Ray, Kubernetes, MLflow, Spark

Career Paths

Prepares learners for roles such as:

  • Machine Learning Engineer
  • AI Engineer
  • MLOps Engineer
  • Data Engineer (ML Focus)
  • DevOps Engineer (ML Systems)

Admission Requirements

Prerequisites

A bachelor’s degree in any field · Python programming · Linear algebra and probability

Helpful Background

Experience training a machine learning model

How You'll Learn

Learning Format

Flexible + live: Watch lessons any time, plus two live Jitsi sessions a week (recorded)

Assessment Method

Projects graded by instructors on a four-level mastery rubric

Support Structure

Instructor grading with written feedback, office hours, and peer collaboration

Launch pricing in US dollars, paid one term at a time

Financial planning assistance available
