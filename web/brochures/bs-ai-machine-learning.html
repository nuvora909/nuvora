B.S. Artificial Intelligence & Machine Learning

From Python and the maths of ML to deep learning, LLM systems and MLOps, with evaluation built in from the start.

Program Overview

Level

Bachelor’s-level program

Duration

3–4 years part-time

Weekly Commitment

8–12 hours/week

Credential

Nuvora certificate of completion · not an accredited degree

What You'll Learn

Core Competency: Machine Learning & Generative AI

Specialization Track: data-to-ai

Capstone Project: Build and ship an ML system with an evaluation plan, a model card and a monitoring dashboard.

Terms of Study

  1. Python for AI – Python Proficiency
  2. Mathematics for AI – Linear Algebra & Probability
  3. Data Foundations – SQL & Data Wrangling
  4. Machine Learning Foundations – Supervised Learning
  5. Deep Learning Fundamentals – Neural Networks
  6. Generative AI & LLMs – Prompt Engineering & Applications
  7. MLOps & Deployment – Model Serving & Monitoring
  8. Computer Vision & NLP – Specialized Applications
  9. AI Ethics & Responsibility – Bias, Fairness & Safety
  10. Capstone: AI & ML Capstone Project

Tools & Technologies

Python, NumPy, PyTorch, scikit-learn, Hugging Face, Docker, MLflow

  • AI Researcher
  • Computer Vision Engineer
